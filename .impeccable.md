# Impeccable — Design Context

> condensed brief loaded by `/impeccable` design skills. When the two disagree, VISION.md wins.

## Design Context

### Users
Power users who already live in Linear, Arc, Raycast, Things, Cron, Vercel, Notion. They keep
20–100+ tabs open across windows and feel the chaos. Context of use: mid-work, fast, keyboard-first,
glancing at the toolbar icon many times a day. They will pay $5/mo only if it *feels* like a premium
utility, not a free extension. Job-to-be-done: tabs organize themselves quietly, on-device, while the
user stays in flow and in control.

Four surfaces, distinct roles:
- **Popup** (320×auto) — dense information *scoreboard*, not a control panel. No standalone buttons.
- **Sidepanel** (400px persistent) — the calm cross-window observatory. Where white space lives.
- **Options** (≤720px centered) — reads like a *product manual*, sectioned by intent, prose + inline controls.
- **Onboarding** (full-page, first install) — 3 steps, ~30s, no email/account/telemetry.
- **Ambient** — toolbar badge/icon, tooltip, context menu, omnibox, sparse notifications. The popup is
  *not* the only window into the extension; the icon alone conveys working / suggesting / downloading / focus / attention.

### Brand Personality
Three words: **quiet, quick, inevitable.** (Supporting: earned, honest.)
- **Quiet** — default state is one icon + a subtle glyph. No nags, no red count badges, no notifications for routine actions. Trust through restraint.
- **Quick** — every action settles <200ms. No spinners on grouping; run optimistically, animate the result in. ⌘K is the primary entry point.
- **Inevitable** — when auto-mode acts it should feel like *Chrome itself* did it, not an extension popping up. The "AI acted" toast is a whisper, never a notification.
- **Honest** — the privacy claim is reinforced visually: a `●local` dot on every AI action; a tier badge showing which model ran. Nothing leaves the device, ever (locked product rule — no cloud LLM).

Emotional goal: calm confidence. The user should trust it enough to never open the popup.

### Aesthetic Direction
Premium-utility, warm-editorial. The category we live in: Linear / Things / Cron / Stripe-docs —
**not** the saturated rainbow-gradient Chrome-extension look (Workona, Toby, Bardeen).

- **Theme: auto (follow system).** Both light and dark are first-class; Chrome users skew system-pref. Light is warm-neutral, not cold gray.
- **Color** — warm neutrals (`--ink-*`, a warm paper white `#FAFAF7`, near-black `#0E0D0A`), single signal accent **burnt orange `#C6592B`**, never used decoratively. Per-workspace colors derived from accent via low-saturation hue rotation, bounded to a 12-color preset. Status colors (green/amber/red) only when genuinely meaningful.
- **Elevation** — *no drop shadows in light mode* (reads as Material). Inset hairlines + bottom-edge borders instead. True elevation only on command palette + toast. Dark mode: single soft inset glow.
- **Spacing** — off-grid scale **2, 6, 10, 14, 22, 36** (deliberately NOT Tailwind 4/8/12/16/24/32, which reads as generic admin panel).
- **Radii** — mixed deliberately (4 pills / 8 cards / 14 surfaces), never the universal-12 default.
- **Motion** — every state change animates but nothing >600ms. Spring `linear()` easing for group/dedupe results. The "AI acted" icon pulse fires *exactly once*, never loops. `prefers-reduced-motion` mandatory → opacity-only fades.
- **Iconography** — Lucide stroke icons, 14px / 1.5px stroke, ~12 total. Emoji is *identity* (workspace glyphs), never a UI control. The `●local` dot is the brand; no wordmark in the popup.

**Typography override (intentional):** impeccable bans Inter, but this product LOCKS
**Inter Display + Inter (cv11, ss01, ss03, tnum) for sans, JetBrains Mono for shortcuts/keys.**
This is a deliberate Linear-aligned product decision in VISION.md §2, not a reflex default. Do not
substitute a different sans to satisfy the generic ban — the cv11 single-story `a` and tabular figures
are core to the intended feel. Keep type hierarchy with strong size contrast (modular 1.125, 12px base in popup).

**Anti-references (explicitly NOT this):** Plasmo rainbow-gradient AI extensions · "Magic ✨" copy ·
floating action buttons · emoji-soaked landing pages · cyan-on-dark / purple-blue-gradient AI palette ·
gradient text · side-stripe accent borders · glassmorphism · saturated category colors · cold Vercel blacks ·
"list of buttons in a 320px popup".

### Design Principles
1. **Restraint is the product.** Every pixel must earn its place; default to showing less. Animations carry information, never decorate.
2. **Information over controls.** Surfaces inform; actions live behind ⌘K, context menu, and auto-mode. The popup is a scoreboard, not a dashboard.
3. **The `●local` dot is sacred.** Privacy is the differentiator — reinforce it visually on every AI action. No surface ever implies data left the device.
4. **Ambient-first.** State must be glanceable from the toolbar icon alone. The popup is not the only window in.
5. **Warm, off-grid, hairline-not-shadow.** These three choices separate us from generic Tailwind/Material AI slop. Hold the line on all three.

### Accessibility (non-negotiable)
- AA contrast on all text, both themes. Burnt-orange accent tested at 14px against light surfaces and dark `--ink-0-dk`; recalibrate if it fails AA.
- Focus ring: 2px outset accent, 4px offset, visible everywhere. No `:focus { outline: none }`.
- All custom controls: `aria-label` + role; workspace cards are `<button>`, not `<div>`.
- `prefers-reduced-motion` mandatory. Options page targets Lighthouse a11y 100.
